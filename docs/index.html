MyEyes!

A dark mode for the web, built for eyes that need a break. Pages are dark from the first frame, and everything works from the keyboard.

Get the latest release

Install (Firefox 140 or newer)

  1. Download the .xpi file from the latest release.
  2. In Firefox open about:addons, click the gear and choose Install Add-on From File….

The file is signed by Mozilla, so it stays installed. From version 0.1.1 on, Firefox updates it by itself.

Your data

MyEyes! collects nothing: no accounts, no analytics, no telemetry. Read the privacy policy.
