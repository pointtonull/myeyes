# MyEyes! UI assets

A practical starter asset kit recreated from the approved popup design.

- `icons/`: independent SVG icons for enabled/disabled, Dynamic (JS CSS rewriting), Filter+ (linear CSS filters), Custom, Theme, brightness, contrast, saturation, sepia, AI Enhance, Clean Up, settings, defaults, and utility actions.
- `brand/`: gradient glasses mark and compact wordmark.
- `mascot/`: lightweight SVG reinterpretations of the blob (happy, stressed, AI).
- `reference/`: the approved full popup mockup as a visual reference.
- `palette.json`: suggested design colors.

SVGs are editable and transparent; PNG variants are generated from them. The mascot vectors are simplified reinterpretations, **not exact isolated artwork** from the rendered reference. Buttons, sliders, borders, and glows should be implemented with CSS for crisp, responsive rendering.

The interface uses Enabled/Disabled; Dynamic/Filter+/Custom/Theme; four sliders; AI Enhance and Clean Up; and a Default for new sites selector with Themes in its menu. Custom = base engine + tweaks; a saved Theme is reusable.
